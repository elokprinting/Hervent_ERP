# HERVENT ERP Frontend

Standalone React application built with Vite and Tailwind CSS. It is kept
separate from the Laravel API in `../backend`.

## Requirements

- Node.js 22.12 or newer
- npm

## Development

From this directory:

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

Frontend dependencies and build output stay in this directory; Laravel
dependencies and runtime files stay in `../backend`.
